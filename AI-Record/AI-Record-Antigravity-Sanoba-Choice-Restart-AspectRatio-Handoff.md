## 一、本轮解决的核心问题与踩坑实录

在将基于 RibbonEngine 的通用模板移植到《魔女的夜宴》过程中，暴露了多项严重影响玩家游玩体验与视觉呈现的问题。本轮针对以下五个核心缺陷进行了深度修复与架构升级：

### 1. 选项多时垂直拥挤误触与缺少确认机制
- **踩坑现象**：在共通线中遇到 4 选项（例如乐队投票选项）时，原版垂直居中堆叠使单个卡片高度不足 28px，在词典笔的狭长触控屏上极易误触；且旧版“点击即刻跳转”导致玩家无法看清和确认选择。
- **方案实现**：
  - 采用 **720×196 绝对定位双栏布局**（`.game-choice-panel`，left: 40px, top: 12px）；
  - 左侧 `.game-choice-options`（520×160，4 个选项单项 32px，间距舒展均匀）；
  - 右侧 `.game-choice-side`（156×160）常驻 `.game-choice-confirm-btn`（144×84，【确定选择 CONFIRM】大按钮）；
  - 点击选项仅切换选中态高亮（金色边框与发光），右侧确定按钮高亮激活；点击确定后才真正执行跳转；未选任何项时确定按钮半透明禁用。

### 2. 选过一遍后无法更改，流程图无法重入选项
- **踩坑现象**：玩家选择过某个选项后，剧情再次推进到该处或从流程图点击跳转到该选择支时，弹层被直接跳过，玩家无法改选其他路线分支。
- **方案实现**：
  - 移除了 `applyCurrentLine` 中对历史选择的静默跳过守卫；
  - 只要到达选择行，必定弹出选择支弹层，并默认高亮上次选中的项；
  - 玩家点击不同选项并确定后，自动执行好感度反向结算，扣除旧增量并累加新增量，动态重算 routes 与 flags；
  - 流程图节点跳转清除内部刚确认标记，确保重入必定弹出改选层。

### 3. 粗暴的“好感度比大小”导致个人线进入错乱
- **踩坑现象**：很多移植在共通末尾采用“比较哪个角色好感度分值最高就进入谁的路线”，导致多条路线前置条件冲突，部分角色路线甚至永远无法触发。
- **方案实现**：
  - 严格对照游戏原版脚本的分歧判定规则：
    - 和奏线：在 018 节（行号 8485）判定，满足 `f.wak_flag == 3` 且处于二周目时进入和奏专属路线；
    - 其余四女主：在 019 节（行号 9220）依原版优先级依次判定（宁宁 `nen >= 4`、巡 `meg >= 4`、紬 `tsu >= 2`、憧子 `tou >= 3`）；
    - 未满足任何女主条件时平滑进入共通结局，避免粗暴的最高分比大小。

### 4. 16:9 原图被带鱼屏拉伸压扁（畸变甚至达 256%）
- **踩坑现象**：存读档槽位缩略图（164×36）将 16:9 原图拉伸为 4.55:1，人物严重面条化；存档大图预览（230×94）拉伸为 2.45:1；立绘特写全屏背景图被强制设为 800×220（3.63:1），纵向被活生生压缩了一半。
- **方案实现（16:9 比例守护规约）**：
  - 存档大图预览：设为 `width: 167px; height: 94px; position: absolute; left: 31px; top: 0;`（严格 16:9 居中，左右黑边对称）；
  - 存档槽位小图：设为 `width: 64px; height: 36px; position: absolute; left: 50px; top: 0;`（严格 16:9 居中，杜绝长条面条）；
  - 全屏特写 16:9 背景：设为 `width: 391px; height: 220px; position: absolute; left: 204px; top: 0;`（严格 16:9 居中，杜绝拉伸）；
  - 卡片缩略图：按 16:9 比例结合外层 `overflow: hidden;` 与负 margin 居中裁切。

### 5. 绫地宁宁线二周目重启（Restart）的独立仪式感
- **踩坑现象**：原先采用煞风景的系统选择弹窗让玩家二选一“进二周目还是新游戏”，严重破坏了柚子社原版游戏的剧情沉浸感。
- **方案实现**：
  - 主菜单保留常规的【开始游戏 START】（始终进入共通线）；
  - 一周目通常结局通关后，主菜单额外呈现独立的魔女紫金流光【重新开始 RESTART】入口；
  - 点击后不弹任何对话框，伴随心声独白直接无缝突入二周目时空回溯篇章；右上角保留流程图快捷入口。

## 二、检测与多级验证体系

为确保移植工程具备极高可靠性，建立了三级验证体系：

1. **第 1 级：Node VM 离线逻辑与 DOM 自动化单测（6 套 60 项全绿通过）**：
   - `test_choices_ui.mjs`：测试双栏确认、选项高亮、随时重选、流程图重入、好感度增量与反向结算、路线分歧决议；
   - `test_core_ui.mjs`：测试三栏视口、系统菜单两行六按钮、Backlog 渲染、舞台缩放、音频持久化；
   - `test_flowchart_ui.mjs`：测试路线连线 DAG 拓扑与节点精确跳转；
   - `test_gallery_ui.mjs`：测试四 Tab 切换、CG 分页与拖拽、立绘换装、音乐盒曲目；
   - `test_afterstory_ui.mjs`：测试通关守护、未通关锁定遮罩与独立剧本切入；
   - `test_nene_restart.mjs`：测试二周目重启按钮状态质变与独白剧情衔接。
   - 运行命令：
     ```bash
     node --experimental-vm-modules --test tools/test_*.mjs
     ```

2. **第 2 级：构建静态尺寸与 Falcon CSS 语法校验**：
   - 提取所有页面的 CSS 规则；
   - 严格拦截非法的复合简写（`border`、`padding`、`margin` 复合属性）；
   - 严格校验所有容器与组件的静态声明尺寸全部 `<= 800×220`。
   - 运行命令：
     ```bash
     python3 build.py --check
     ```

3. **第 3 级：真机拟人化 ADB 巡检与多模态读图审查**：
   - 真机安装：`python3 build.py --serial <序列号> --install`；
   - 屏幕截图：`adb -s <序列号> shell "miniapp_cli capture /tmp/screen.png"` 并拉取到本地；
   - 人工与多模态模型严格逐页核验截图，确认文字无截断、立绘无畸变、边框无溢出。
